PF Frontend Application

Overview
This frontend application provides a simple and clean interface for creating RPFs (Request for Proposal), sending them to vendors, managing vendor responses, and viewing AI-based proposal recommendations.
The UI allows the user to write requirements in a messy or unstructured format, select vendors, track proposals, and trigger the AI ranking process.
It is built with React and communicates with the backend through REST APIs.

Features
1.Create RPFs using messy or free-form text.

2.View all previously created RPF entries.

3.Select vendors and send RPF details directly through the UI.

4.Track vendor proposals.

5.Request AI recommendations and view ranked proposals.

Tech Stack
1.React
2.React Router
3.Axios
4.CRA
